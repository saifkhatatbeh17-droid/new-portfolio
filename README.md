# Personal Portfolio — Saif Eddin Al-Khatatbeh

A responsive and interactive personal portfolio website designed to showcase the professional journey, qualifications, experience, and skills of Saif Eddin Al-Khatatbeh.

## 🛠️ Tech Stack & Technologies

* **HTML5**: Structured markup for document content.
* **CSS3**: Custom styling, CSS variables, typography, animations, and hover transitions.
* **Bootstrap 5.3**: Responsive navbar, grid structure, and mobile-friendly components.
* **Bootstrap Icons**: Visual icons for contact details and sections.
* **Google Fonts**: Typography using `Cormorant Garamond` (headings) and `Poppins` (body text).

## 📁 Project Structure

```text
.
├── index.html   # Main HTML markup and structured sections
└── style.css    # Custom styles, color palette, and responsiveness adjustments

```

## 🌟 Key Sections

* **Hero Section**: Introduces the full name, roles, location, and key credentials.
* **About**: Summarizes academic achievements in Arabic Literature and the transition into programming.
* **Experience**: Highlighted experience as an Arabic Language Educator and News Editor.
* **Qualifications & Training**: Educational background (BA & Higher Diploma) alongside completed professional training courses.
* **Skills**: Grouped into Soft Skills, Technical Skills, and Language Proficiencies.
* **Projects**: Displays personal projects including web portfolio development and curriculum designs.
* **References**: Professional links to mentors and recommendations.
* **Footer**: Direct contact information (email, phone, location) and copyright notice.

## 🚀 Getting Started

1. Download or clone the repository files.
2. Open `index.html` in any web browser (e.g., Chrome, Edge, Safari, Firefox).
